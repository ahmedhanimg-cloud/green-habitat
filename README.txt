GREEN HABITAT — نسخة HTML / CSS / JavaScript

الملفات:
- index.html: الصفحة الرئيسية.
- contact.html: صفحة التواصل.
- style.css: الألوان والتخطيط والتجاوب.
- script.js: قائمة الهاتف وتبديل صور الخدمات ورسالة النجاح.

طريقة التشغيل:
1. فك ضغط الملف وافتح المجلد في VS Code.
2. افتح index.html باستخدام إضافة Live Server، أو افتحه مباشرة في المتصفح.
3. زر «تواصل معنا» يفتح contact.html.
4. نموذج التواصل يرسل إلى greenhabitatesgc@gmail.com عبر FormSubmit. في أول استخدام يجب تأكيد البريد من رسالة FormSubmit.

ملاحظة: صور الموقع تستخدم روابط التخزين المنشورة، لذلك يلزم اتصال بالإنترنت حتى تظهر الصور والخطوط.
